# 公槽 TS／IIS／Order 信抓取

貼上一串 TDCC（例如從庫存表篩出 DACN 的那一欄），程式在你選的公槽根目錄底下找每檔的說明書與投資人須知，或檔名含「Order」的 Outlook 信件，複製到你選的資料夾。獨立程式，不跟 FCN Workflow 的面板掛勾。

## 怎麼找檔

跟 FCN Workflow「準備」找商品資料夾的做法一樣：

- 在根目錄底下**任何深度**找名稱剛好等於 TDCC 的資料夾；同一個 TDCC 找到多個同名資料夾時不猜，列為缺件。
- 資料夾裡找檔名剛好是 `<TDCC>_TS.pdf`／`<TDCC>_IIS.pdf`（大小寫不拘）；第一層沒有時會往下層找，找到多份不猜，列為缺件。
- 複製到目的資料夾時檔名不變，同名檔案直接覆蓋。目的資料夾不能放在根目錄底下。

「抓 Order 信」找商品資料夾的方式相同，資料夾裡則改找：

- 任何深度、副檔名 `.msg`、檔名含 `Order`（大小寫不拘）的信件，有幾封就複製幾封。
- 檔名裡沒有 TDCC 的，複製時前面補上 `<TDCC>_`（例如 `Order.msg` → `029199990001_Order.msg`），免得不同商品的同名信件互相覆蓋。
- 同一檔的資料夾裡有同名信件（放在不同子資料夾）時不猜，那一封列為缺件，其他照常複製。

## 使用

1. 需要 Python 3.11 以上（只用標準函式庫，不必另外安裝套件）。
2. 雙擊 `launch.cmd`。
3. 按「根目錄」旁的「變更…」選商品資料夾所在的根目錄（例如換做 DACN 時選 DACN 的根目錄）；按「複製到」旁的「變更…」選目的資料夾。兩個都只能用按鈕改，選過會記住，下次打開直接沿用。
4. 把 TDCC 貼到左邊（一行一個、空白或逗號分隔都可以，標題列等非 12 位數字會略過；Excel 掉了開頭 0 的 11 位數字會自動補回）。
5. 按「抓 TS／IIS」或「抓 Order 信」。右邊逐檔顯示 TS／IIS 有沒有抓到（或抓到幾封 Order 信），有問題的紅字寫原因；「複製缺件的 TDCC」把有問題的 TDCC 複製到剪貼簿。

選過的根目錄與目的資料夾記在本機 `.local/settings.json`（不進 Git）。
