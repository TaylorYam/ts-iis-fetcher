# 公槽 TS／IIS 抓取

貼上一串 TDCC（例如從庫存表篩出 DACN 的那一欄），程式到公槽依商品的根目錄找每檔的說明書與投資人須知，複製到你選的資料夾。獨立程式，不跟 FCN Workflow 的面板掛勾。

## 公槽擺法

```
<根目錄>\<TDCC>\<TDCC>_TS.pdf
<根目錄>\<TDCC>\<TDCC>_IIS.pdf
```

- 資料夾名稱剛好是 TDCC 的優先；沒有時接受以 TDCC 開頭的資料夾（例：`029199990001 某某`）。同一個 TDCC 有多個這種資料夾時不猜，列為缺件。
- 檔名結尾要剛好是 `_TS.pdf`／`_IIS.pdf`（大小寫不拘）。資料夾第一層沒有時會往下層找；找到多份不猜，列為缺件。
- 複製到目的資料夾時檔名不變，同名檔案直接覆蓋。

## 使用

1. 需要 Python 3.11 以上（只用標準函式庫，不必另外安裝套件）。
2. 雙擊 `launch.cmd`。
3. 選商品（FCN、DACN、SUPERBALL，或直接輸入新名稱），第一次用時按「選擇…」設定該商品的公槽根目錄；選「複製到」的資料夾。
4. 把 TDCC 貼到左邊（一行一個、空白或逗號分隔都可以，標題列等非 12 位數字會略過；Excel 掉了開頭 0 的 11 位數字會自動補回）。
5. 按「開始抓取」。右邊逐檔顯示 TS／IIS 有沒有抓到，有問題的紅字寫原因；「複製缺件的 TDCC」把有問題的 TDCC 複製到剪貼簿。

各商品的根目錄、上次選的商品與目的資料夾記在本機 `.local/settings.json`（不進 Git）。預設的商品清單與根目錄在 `config/products.toml`。

## 開發

```
py -3 -m pytest
```
